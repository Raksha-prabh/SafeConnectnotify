# 🛡️ SafeConnect Notify – AI-Powered Social Media Security System

## 📌 About

SafeConnect Notify is a web-based social media security application developed using **Python (Flask)** and **MySQL**. It helps users identify suspicious social media accounts, detect fake profiles, check the safety of friend requests, and analyze scam messages using a **rule-based algorithm**.

## ✨ Features

* 🔍 AI Profile Analysis
* 👤 Fake Account Detection
* 🤝 Friend Request Safety Checker
* 💬 AI Scam Chat Analyzer
* 📊 Interactive Dashboard with Chart.js
* 🔔 Live Notifications
* 🔐 User Login & Registration

## 🛠️ Technologies Used

* Python
* Flask
* MySQL
* HTML
* CSS
* Bootstrap 5
* JavaScript
* Jinja2
* Chart.js

## 🚀 How to Run

1. Clone the repository.
2. Install the required Python packages.
3. Create the **safeconnect** MySQL database.
4. Update the database configuration in `app.py`.
5. Run the application:

```bash
python app.py
```

Open your browser and visit:

```
http://127.0.0.1:5000
```
